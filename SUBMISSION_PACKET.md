# PrizePilot Submission Packet

## Project

PrizePilot

## One-Line Pitch

A human-in-the-loop AI workflow agent that finds, scores, plans, drafts, and compliance-checks legitimate prize and challenge submissions without ever submitting for the user.

## Hackathon Track

All Things Agentic Hackathon: Taskmaster

## What To Submit Manually

- Public code repository URL.
- Working app URL if deployed to Cloud Run.
- Demo video link.
- README with setup and Cloud Run instructions.
- Architecture diagram.
- Short description emphasizing Gemini 3.5+, Google GenAI SDK, Cloud Run, Firestore, and compliance gates.

## Claims Needing Final Verification

- Official All Things Agentic deadline and prize rules.
- Track-specific judging criteria.
- Exact Gemini and Google Cloud requirements from official rules.
- Any eligibility, geography, tax, or IP clauses.
- Final deployed Cloud Run URL and logs.

## Manual Approval Checklist

- User reviewed official rules.
- User verified all claims and citations.
- Compliance scan is Safe or manually accepted as Needs Review.
- No fake credentials, nonprofit claims, endorsements, or citations.
- User submits manually outside PrizePilot.
