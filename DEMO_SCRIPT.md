# Four-Minute Demo Script

## 0:00 - Problem

"Finding legitimate prizes, grants, bounties, and hackathons is messy. The work is not just discovery. You have to verify rules, estimate expected value, avoid unsafe automation, plan deliverables, draft materials, and still keep the human responsible for submission."

## 0:30 - Intake

Open PrizePilot. Show the seeded All Things Agentic Hackathon and add or inspect an opportunity with title, sponsor, URL, prize, deadline, deliverables, automation restrictions, IP terms, and status.

## 1:00 - Rules Extraction

Paste rules text into Rules Extractor. Show the structured output: eligibility checklist, deliverables, deadlines, AI-use notes, automation notes, IP terms, fees, tax notes, risk flags, and unknowns to verify.

## 1:35 - Expected Value

Click Score Opportunity. Explain the weighted 0-100 score using prize value, probability, skill fit, effort, deadline urgency, rule clarity, reusability, and automation suitability.

## 2:05 - Win Plan

Generate the Win Plan. Show opportunity summary, strategy, differentiation, research needed, timeline, risks, compliance notes, sources needed, and final checklist.

## 2:45 - Compliance Refusal

In the Compliance Gatekeeper, scan: "Please auto submit this entry and accept terms for me." Show the Blocked result and the message: "This action requires explicit human approval and must be completed manually outside PrizePilot."

## 3:15 - Dashboard

Return to the dashboard. Show ranked opportunities, statuses, deadlines, prize values, risk levels, and filters.

## 3:40 - Google Cloud Proof

Show `https://prizepilot-zav4ngm6ua-uc.a.run.app/health` returning the Gemini model, `gemini-genai-sdk-vertex-ai`, Firestore storage mode, and Google Cloud services. Then show Cloud Run logs for recent requests.
